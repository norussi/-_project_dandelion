# 민들레 — DANDELION  v0.4.1

> 경험해 보지 못한 상황을, 게임으로 체험하다

Godot 4.3 이상을 대상으로 작성한 체험형 교육 게임입니다. 메인 메뉴에서 체험을 골라 시작합니다.
현재 체험은 **모드 1: 시각장애인 보행 체험**과 **모드 2: 화재 대피 체험**(둘 다 1인칭 3D)입니다.
외부 에셋, 플러그인, 인터넷 연결이 필요하지 않습니다. Godot 3에서는 열리지 않습니다.

## 실행

**실행 파일로 바로 실행**: `build/windows/Dandelion.exe`(또는 GitHub Releases에서 받은 파일)를 더블클릭합니다. Godot가 필요 없습니다. 게임 데이터가 실행 파일 하나에 들어 있습니다.

**Godot에서 열기**

1. ZIP 압축을 풉니다.
2. Godot 4 프로젝트 관리자에서 **가져오기 / Import** → `Dandelion/project.godot`.
3. **F5**로 실행 → 메인 메뉴 → **플레이** → **시각장애 보행** `시작하기` → `연습부터 시작하기`(또는 `바로 출발`).

화면이 거의 검은 것은 의도된 동작입니다. 화면 아래에 흰 지팡이가 보이고, 지팡이로 짚은 곳만 잠시 드러납니다.
한글이 네모로 나오면 Noto Sans KR 등 한글 글꼴을 설치하세요. 헤드폰을 권장합니다.

## 메인 메뉴 (v0.2.0 추가)

- **배경**: 해 질 녘 길가, 보도블록 틈에 홀로 핀 민들레. 꽃대가 바람에 흔들리고, 솜털 씨앗이 날아가고, 차가 지나가면 바람이 일어 씨앗이 한꺼번에 흩날립니다. 외부 이미지 없이 코드로 그립니다(`menu/roadside_scene.gd`).
- **플레이**: 체험 선택 화면. 왼쪽은 *시각장애 보행*, 오른쪽은 *화재 대피*입니다.
- **설정**: 조작 / 키 설정 / 소리 / 화면·접근성 네 탭. 각 탭은 모든 체험에 적용되는 **공통** 묶음과 체험 전용 묶음으로 나뉩니다. 바꾼 값은 바로 적용되고 `user://settings.cfg`에 자동 저장됩니다. 게임 중 일시정지 화면의 **설정** 버튼으로도 열 수 있습니다.
- **GitHub 바로가기**: 오른쪽 아래. 저장소를 브라우저로 엽니다.
- 일시정지 화면과 엔딩 마지막 페이지에 **메인 메뉴** 버튼이 있습니다.

### 설정 항목

| 탭 | 항목 |
|---|---|
| 조작 | 공통: 마우스 감도(×0.2~3.0), 마우스 상하 반전, 시야각(60~100°) · 시각장애 보행: 걸을 때 지팡이 자동으로 짚기, 조준점 표시 |
| 키 설정 | 시각장애 보행 / 화재 대피를 골라서 설정. 공통(두 체험이 같은 키를 씀): 이동 4방향, 몸 낮추기(누르고 있기), 상호작용, 일시정지 · 시각장애 보행: 서두르기, 바라보는 곳 짚기, 발 앞 짚기, 휴대폰 안내, 다시 시작 · 화재 대피: 자세 낮추기 켜고 끄기, 코와 입 막기, 왼쪽/오른쪽으로 돌기. 같은 체험에서 이미 쓰는 키를 고르면 두 동작의 키가 맞바뀌고, 맞바꾸면 다른 체험에서 키가 겹치게 될 때는 바뀌지 않고 안내가 나옴 |
| 소리 | 공통: 전체 음량 · 시각장애 보행: 음성 안내(TTS) 켜기, 음성 음량, 음성 속도, 음성 미리 듣기 |
| 화면·접근성 | 공통: 전체 화면, 글자 크기(100/115/130%, 화재 대피의 게임 화면 글자는 제외), 화면 흔들림·번쩍임 끄기 |

키를 바꾸면 게임 안의 안내 문구(시작 화면, 도움말, 화면 위 상태 줄, 물체 설명)에도 바꾼 키 이름이 나옵니다.

## 조작 (기본값, 설정에서 변경 가능)

| 입력 | 기능 |
|---|---|
| W / S | 앞 / 뒤로 걷기 |
| A / D | 옆걸음 |

## v0.3.1 변경 사항

- **엘리베이터 버튼판 찾기 개선**
  - 칸 안 세 벽에 30cm 격자무늬를 넣어, 지팡이로 짚으면 칸의 크기와 벽이 드러납니다.
  - 버튼판을 문틀 바로 안쪽 오른쪽 벽(벽에서 6cm 튀어나옴)으로 옮기고, 두꺼운 테두리와 버튼 줄 무늬를 넣었습니다. 지팡이로 짚으면 “엘리베이터 버튼판이다”라고 알려 줍니다. (이전에는 버튼판이 문틀 벽 속에 묻혀 있어 짚이지 않았습니다)
  - 칸 안 어디에 서 있든 E로 버튼판을 더듬을 수 있고, 칸에 들어서면 버튼판 위치를 안내합니다.
- **보행 신호 빨간불 60초** (녹색 15초 그대로)
- **빨간불에 차도에 들어서면**: 차가 급정거하며 경적을 울리고(경적 횟수 기록), 잠시 뒤 화면이 어두워지며 건너기 전 횡단보도 앞으로 돌아갑니다. 어느 쪽에서 건너든 그쪽 횡단보도 앞으로 돌아갑니다.
- **건너편 기둥에도 음향신호기 버튼**: 병원 쪽에서 건널 때도 E로 버튼을 누를 수 있습니다. 위치 알림음은 서 있는 쪽 기둥에서, 녹색 유도음은 건너편 기둥에서 납니다.

## v0.3.0 변경 사항

### 1. 자동 좌우 짚기 복원 (클릭 짚기 유지)
- v0.1.0의 이점 촉타법을 다시 넣었습니다. 걸음 위상에 맞춰 지팡이 끝이 좌우 호(반각 0.47rad, 약 ±0.33m)를 그리고, 한 걸음마다 한쪽 끝을 짚습니다. 짚는 쪽의 반대 발이 디딥니다.
- 호를 그리는 도중 지팡이가 물체에 걸리면 걸린 자리가 드러나고, 점자블록을 스치면 ‘드르륵’ 소리와 함께 알려 줍니다.
- 좌클릭(바라보는 곳 짚기)과 Space(발 앞 짚기)는 그대로 남아, 자동 동작 위에 끼어들어 직접 확인할 수 있습니다.
- 설정 → 조작 → ‘걸을 때 지팡이 자동으로 짚기’로 끌 수 있습니다 (끄면 v0.2.x처럼 클릭으로만 짚음).

### 2. 웅크리기 (기본 Ctrl)
- 누르고 있는 동안 몸을 낮춥니다. 눈높이 1.6m → 1.0m, 몸 높이 1.7m → 1.15m, 손(지팡이 잡는 높이)도 함께 내려갑니다.
- 골목의 간판(1.46m~)과 공사 파이프(1.51m~) 아래를 지나갈 수 있습니다. 머리를 부딪히면 웅크리기 키를 알려 줍니다.
- 돌출물 아래에서 키를 떼도 머리 위가 막혀 있으면 일어서지 않습니다.

### 3. 연습 구간 (튜토리얼)
- 시작 화면에서 `연습부터 시작하기`를 누르면 집 앞 아파트 1층 복도에서 시작합니다. `바로 출발`이나 일시정지 화면의 `연습 건너뛰기`로 넘길 수 있습니다.
- 다섯 단계: ① 걷기(자동 짚기) ② 점자블록 따라가기(꺾이는 점형블록) ③ 천장 배관 아래 웅크려 지나가기 ④ 휴대폰 안내(Q) 들어 보기 ⑤ 공동현관 열림 버튼을 E로 누르기. 화면 위 상태 줄에 `연습 n/5`가 나옵니다.
- 열린 문으로 나가면 골목 입구에서 본편이 시작되고, 연습 중 기록(시간, 접촉 횟수)은 지워집니다.

### 4. 도와주는 사람
- 병원 밖(골목, 큰길)에서 점자블록을 발로도 지팡이로도 **1분 동안** 건드리지 못하면, 지나가던 사람이 다가와 TTS로 말을 겁니다.
  “저기요, 혹시 길을 찾고 계세요? 도와드릴까요?” → “도와드릴게요. 제가 팔을 살짝 터치해도 될까요?” → “제 팔꿈치를 잡으세요. 제가 반 걸음 앞에서 천천히 걸을게요…”
- 함께 걷는 동안 화면이 어두워지고 발소리가 들린 뒤, **마지막으로 점자블록을 건드렸던 곳**에 내려 줍니다. 신호기 앞에서 기다리는 동안은 시간을 세지 않습니다.
- 먼저 묻고, 동의를 구하고, 팔꿈치를 내어 주는 실제 안내 예절을 대사에 담았습니다. 엔딩에 ‘도움을 받은 횟수’가 기록됩니다.

### 5. 엔딩 ‘04 / 함께 걷는 법’
- 엔딩이 네 페이지가 되었습니다. 마지막 페이지에서 길에서 할 수 있는 일(점자블록 위 물건 치우기, 공사 시 우회로, 돌출물, 고장 난 음향신호기 신고)과 도움을 드리는 방법(먼저 묻기, 팔꿈치 내어 주기, 구체적인 방향, 안내견 예절, 떠날 때 알리기)을 정리합니다.

### 6. 아이콘
- 민들레 아이콘(`icon.png`, `icon.ico`)을 추가했습니다. 게임 창, 부팅 화면, Windows 실행 파일(`Dandelion.exe`)에 들어갑니다.

## v0.2.0 변경 사항

### 0. 메인 메뉴, 체험 선택, 설정 (위 ‘메인 메뉴’ 참고)
- 프로젝트 이름을 임시 이름 Echo Road에서 **민들레(Dandelion)**로 통일했습니다.
- 일시정지 중 하단 안내 문구가 패널 뒤로 겹쳐 보이던 문제를 고쳤습니다. 도움말이 길거나 글자를 키워도 패널 안에서 스크롤됩니다.

### 1. 좌클릭으로 지팡이 짚기 (자동 좌우 짚기 삭제)
- 걸을 때 자동으로 좌우를 두드리던 기능을 삭제했습니다. 이제 플레이어가 직접 짚어야 합니다.
- 좌클릭하면 화면 중앙 조준점이 가리키는 곳을 지팡이 끝으로 짚습니다. 지팡이가 뻗었다가 돌아오는 동작(0.43초)이 나오고, 짚은 순간 반향 정위가 발동합니다.
- **짚을 수 있는 범위**는 실제 긴 지팡이(1.2m)를 기준으로 제한됩니다.
  - 손(배꼽 높이, 몸 중앙)에서 지팡이 끝까지 **1.2m 이내**: 바닥에서는 발 앞 약 0.4 ~ 1.0m
  - 몸 **앞쪽**만, 높이 **1.3m 이하**만 (벽, 기둥, 차체 측면도 이 범위 안이면 짚을 수 있음)
  - 더 먼 곳을 겨누면 **같은 방향의 가장 먼 바닥**을 짚습니다. 조준점과 바닥 고리가 회색으로 바뀌어 범위 밖임을 알려 줍니다.
  - 손에서 지팡이 끝 사이에 물체가 있으면 그 물체에 걸립니다.
- 짚지 않고 걸으면 물체에 **몸으로 부딪혀서야** 알게 됩니다 (흔들림, 둔탁한 소리, 설명).
- 반향 범위: 지팡이 끝 반경 0.38m(물체는 0.65m), 넓은 면의 희미한 울림 약 2m.

### 2. 신호등 횡단보도와 음향신호기
- 골목 끝에 왕복 2차로 큰길(폭 8m)이 있습니다. 차가 양방향으로 다니고 엔진음이 들립니다.
- **보행 신호 주기**: 빨간불 60초 / 녹색 15초 (v0.3.1). 녹색일 때 차는 정지선에서 멈춥니다.
- 양쪽 기둥(v0.3.1부터 건너편 포함)의 **음향신호기**:
  - **위치 알림음** '딱, 딱'(1.3초 간격)으로 기둥 위치를 찾을 수 있습니다.
  - E로 버튼을 누르면 음성 안내: 빨간불이면 “빨간 신호입니다. 잠시 기다려 주십시오…”, 녹색이면 “녹색 신호입니다. 남은 시간 N초…”
  - 녹색으로 바뀌면 “녹색 신호입니다. 건너가십시오.”, 5초 전에는 “신호가 곧 바뀝니다.”
  - 버튼 상자 윗면의 튀어나온 화살표가 건너는 방향을 알려 줍니다.
- 녹색 동안 **건너편 기둥에서 유도음**(뚜르르)이 나서 그쪽으로 걸어가면 됩니다.
- 횡단보도의 흰 칠은 지팡이로 느낄 수 없으므로 화면에도 그리지 않습니다. 연석과 양쪽 점형블록만 느껴집니다.
- 빨간불에 차도로 들어가면 차가 급정거하며 경적을 울리고, 건너기 전 자리로 돌아갑니다 (엔딩에 횟수 기록). 지나가는 차 근처에서는 소음 때문에 반향이 줄어듭니다.

### 3. 병원 로비, 엘리베이터, 병실
- 현관 앞 점형블록 → 로비 바닥 점자블록 → 엘리베이터 앞 점형블록으로 이어집니다.
- 엘리베이터는 처음에 4층에 있어서, 호출하면 내려오기를 **소리로만** 기다려야 합니다.
- **점자 버튼** (E로 손을 대면 '손끝으로 더듬기' 화면이 열림):
  - 마우스로 버튼 위를 천천히 훑으면 버튼 위 점자가 손끝에 닿고, 0.45초 뒤에 읽은 내용이 표시됩니다. 손이 닿지 않은 점자는 거의 보이지 않습니다.
  - 호출 버튼판: `엘리베이터` 점자, 현재 `N층` 점자, `위` / `아래` 버튼
  - 칸 안 버튼판: `1층`~`5층`, `열림`, `닫힘`, `비상`(관리실 연결 음성)
- 엘리베이터 동작: 도착 차임(올라가는 칸은 한 번, 내려가는 칸은 두 번), “N층입니다. 문이 열립니다.”, “올라갑니다 / 내려갑니다”, “문이 닫힙니다.” 문은 5초 뒤 자동으로 닫히고, 문 사이에 서 있으면 다시 열립니다. 열림 버튼은 닫히는 문을 다시 열고, 닫힘 버튼은 바로 닫습니다.
- 2~5층은 같은 구조의 복도입니다. 문 옆 **점자 명패**를 더듬어 호수를 확인하고 문을 두드립니다. 다른 층에서 두드리면 “여기가 아니다”가 나오고, **5층 503호**에서 두드리면 엔딩입니다.

#### 사용한 점자 (한국 점자 규정 기준)
| 표기 | 점자 | 비고 |
|---|---|---|
| 엘리베이터 | ⠝⠂⠐⠕⠘⠝⠕⠓⠎ | 엘(ㅔ+받침 ㄹ) 리 베 이 터 |
| 층 | ⠰⠪⠶ | ㅊ+ㅡ+받침 ㅇ |
| 1~5 | ⠼⠁ ⠼⠃ ⠼⠉ ⠼⠙ ⠼⠑ | 수표 ⠼ + 숫자 |
| 열림 | ⠳⠐⠕⠢ | ‘열’ 약자 ⠳ |
| 닫힘 | ⠊⠔⠚⠕⠢ | ‘다’ 약자 ⠊ |
| 비상 | ⠘⠕⠇⠶ | ‘사’ 약자 ⠇ |
| 위 / 아래 | ⠍⠗ / ⠣⠐⠗ | |
| 503 호 | ⠼⠑⠚⠉⠀⠚⠥ | 숫자 뒤 ‘ㅎ’은 숫자 0(⠚)과 혼동되므로 띄어 씀 |

> 직접 점역한 것이므로, 실제 전시나 배포 전에는 점역·교정 전문가의 확인을 받으세요.

### 이전 버전에서 유지
- 머리 높이 돌출물(간판, 공사 파이프), 점자블록 위 전동 킥보드, 공사로 끊긴 점자블록, 발전기 소음
- 부정확한 휴대폰 안내 (3~9m 오차, 시계 방향 표현), 보행 속도 1.15m/s

## 새 체험 추가하는 법

1. `stages/<체험 이름>/` 폴더에 씬(.tscn)과 스크립트를 만듭니다.
2. `core/game.gd`의 `STAGES`에 항목을 추가합니다 (`id`, `title`, `subtitle`, `description`, `tags`, `scene`, `preview`, `available`).
   준비 중인 체험은 `available: false`로 두면 ‘준비 중’ 카드로 보입니다.
3. 체험 안에서 메인 메뉴로 돌아갈 때는 `Game.goto_main_menu()`, 키 이름이 필요하면 `Settings.key("동작")`, 감도·시야각 등은 `Settings.값`을 씁니다.
4. 새 키 동작이 필요하면 `core/settings.gd`의 `ACTIONS`에 한 줄을 추가하면 키 설정 화면에도 자동으로 나옵니다.

## 모드 2: 화재 대피

본체는 `res://main.tscn`이고, `stages/fire_escape/fire_escape.gd`가 이를 감싸 일시정지 화면, 메뉴 복귀, 좌클릭 상호작용, 나갈 때 효과음 끄기를 더합니다. 조명을 76개 쓰기 때문에 `project.godot`의 `max_renderable_lights`를 128로 올렸습니다.

민들레 공통 설정(마우스 감도, 상하 반전, 시야각, 화면 흔들림, 전체 음량)과 키 설정이 적용됩니다. 본체 파일은 고치지 않고, `fire_escape.gd`가 본체 플레이어의 감도·시야각을 설정하고 마우스 이동을 뒤집는 방식으로 연동합니다. 키는 `core/settings.gd`가 본체보다 먼저 액션을 등록하고, 본체가 쓰는 다른 액션 이름(`move_forward`, `crouch_hold` 등)은 `ACTION_ALIASES`로 같은 키에 묶습니다. 기본 조작은 W A S D 이동, ← → 돌기, C 자세 낮추기 켜고 끄기, Ctrl 누르고 있는 동안 자세 낮추기, F 또는 우클릭 코와 입 막기, E 또는 좌클릭 상호작용, Esc 일시정지입니다. 좌클릭·우클릭과 엔딩의 R(다시 하기)은 고정입니다. 원래 있던 ↑ ↓ 이동은 키 설정이 동작마다 키 하나라서 빠졌습니다.

## 수정 포인트 (모드 1: `stages/visual_walk/visual_walk.gd`)

| 위치 | 설정 |
|---|---|
| CANE_LENGTH, HAND_LOCAL, TAP_MIN, TAP_MAX_HEIGHT | 지팡이 길이, 잡는 위치, 짚을 수 있는 범위 |
| TAP_COOLDOWN | 연속 짚기 간격 |
| SWEEP_ANGLE, TIP_LIFT, STEP_LENGTH, ECHO_WALK | 자동 좌우 짚기의 호 크기, 지팡이 끝 들림, 걸음 길이, 반향 |
| CROUCH_HEIGHT, CROUCH_EYE, CROUCH_SPEED | 웅크렸을 때 몸 높이, 눈높이, 속도 |
| HELP_DELAY, `_start_help` | 도와주는 사람이 오기까지의 시간(60초), 대사 |
| TUT_X, `_build_tutorial`, TUT_PROMPTS | 연습 구간 위치·구조·안내 문구 |
| TOUCH_RADIUS, OBSTACLE_TOUCH, ECHO_TAP | 촉각 범위, 반향 거리 |
| PED_GREEN, PED_RED, SIGNAL_POLE, SIGNAL_FAR | 신호 주기, 신호기 위치 |
| CAR_SPEED, `_cars_process` | 차량 속도, 출현 간격, 정지·경적 규칙 |
| car_floor 초기값, `_elevator_process` | 엘리베이터 시작 층, 문 열림 시간 |
| TARGET_FLOOR, TARGET_ROOM | 목적지 병실 |
| BR_* 상수, `_open_touch` | 점자 문자열, 버튼판 배치 |
| _describe_contact | 물체에 닿았을 때의 설명 |

새 물체는 `_box(중심, 크기, 라벨, 반사율, 윤곽, 충돌, 머리높이)`로 추가합니다.
연습 구간은 x=-60에 따로 있고, 연습이 끝나면 골목 입구(0, 3)로 순간 이동합니다. 위층(2~5층)은 x=60에 있는 하나의 복도를 공유하고, 엘리베이터를 타면 1층 ↔ 위층 사이를 순간 이동합니다.

## 한계

- 실제 보행 훈련이나 장애 체험의 정확한 재현이 아닙니다. 수치는 체험용으로 단순화한 값입니다.
- 흰 윤곽선은 촉각과 청각 정보를 화면으로 옮긴 허구적 시각화입니다.
- 메뉴 스크린리더 연동, 키 재설정은 미구현입니다. 화면에 시각장애인 캐릭터가 나오는 것과 시각장애인이 플레이할 수 있는 게임인 것은 구별되어야 합니다.
