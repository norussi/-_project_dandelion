# 재난 상황 (화재) - 자료 조사

화재 대피 체험 스테이지의 설계와 개발에 참고한 근거 자료를 정리하는 공간입니다.
각 자료의 발행기관, 링크, 게임 요소와의 대응 관계는 [`fire_references.md`](fire_references.md)에 정리되어 있습니다.

## 자료 목록

| 자료 | 발행기관 | 관련 게임 요소 |
|---|---|---|
| 화재 시 국민행동요령 | 소방청 | 문 손잡이 확인, 엘리베이터 금지, 대피 후 119 신고 |
| 어린이 안전 배움터 소방·안전 | 행정안전부 | 화재 알리기, 낮은 자세, 코와 입 막기 |
| 완강기 사용법 및 전국 체험시설 안내 | 대한민국 정책브리핑 | 완강기 사용 순서 |
| 최근 5년간 아파트 화재통계 분석 | 소방청 | 연기의 위험성 (엔딩 문구) |
| 피난구조설비 – 유도등 | 한국소방안전원 | 유도등 |
| 유도등 및 유도표지의 화재안전기술기준 (NFTC 303) | 소방청·국립소방연구원 | 유도등 설치 기준 |
| 비상경보설비 및 단독경보형감지기의 화재안전기술기준 (NFTC 201) | 소방청·국립소방연구원 | 비상벨(발신기) |
| 피난기구의 화재안전기술기준 (NFTC 301) | 소방청·국립소방연구원 | 완강기 설치 위치 |
| 상황에 따른 대피 판단 안내 | 소방청 | 대피 판단 (게임에 없는 내용) |

원문 파일(PDF)은 아직 올리지 않았고, 링크로만 정리했습니다.

## 사용할 때 유의할 점

- 수치나 규격을 게임에 반영할 때는 요약이 아니라 원문의 해당 조항을 확인합니다.
- 아파트 화재를 대상으로 한 자료와 통계를 학교나 전체 화재의 내용으로 해석하지 않습니다.
- 호흡 게이지와 연기 농도 같은 게임 수치는 근거 자료가 없는 체험용 단순화입니다.
- 게임과 자료가 다른 부분, 추가 조사가 필요한 부분은 `fire_references.md`에 따로 적어 두었습니다.
