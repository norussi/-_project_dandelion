# 시각장애인 보행 체험 게임에 대한 의견 조사

시각장애 보행 스테이지에 담은 불편 사례가 실제 경험과 맞는지, 표현이 적절한지 확인하기 위한 설문입니다. 구글 폼으로 진행하며, 아래는 폼에 들어간 문항을 그대로 옮긴 것입니다.

- **대상:** 시각장애 당사자, 가족·보호자, 지원인력·관련 전문가
- **방식:** 구글 폼 (페이지 7개, 응답자 입장과 개인정보 동의에 따라 분기)
- **필수 문항:** 1, 3~6, 13번 (15번은 쿠폰 응모 페이지에서만 필수)

---

## [페이지 1] 안내 및 응답자 정보

안녕하세요. 저희는 숭실대학교 AI소프트웨어학부 '오픈소스기반기초설계' 수업에서 '민들레' 프로젝트를 진행하고 있습니다.
현재 시각장애인이 보행 중 겪을 수 있는 다양한 상황을 체험하는 게임을 제작하고 있습니다. 이 게임은 상업적 목적이 없는 프로젝트로, 누구나 무료로 이용할 수 있도록 오픈소스로 공개하고 있습니다.
게임은 공공기관의 조사 자료를 바탕으로 개발하고 있지만, 시각장애 당사자분들의 실제 경험과 의견은 아직 충분히 반영하지 못한 상태입니다.
이에 게임 속 상황이 실제 경험과 얼마나 일치하는지, 실제와 다르거나 오해를 불러일으킬 수 있는 표현은 없는지 확인하고자 설문을 진행합니다.
여러분께서 들려주시는 경험과 의견은 게임을 더욱 정확하고 세심하게 개선하는 데 소중한 자료로 활용하겠습니다.

- **소요 시간:** 약 5분
- 필수 표시가 없는 문항은 건너뛰셔도 됩니다.
- 응답 내용은 개인을 알아볼 수 없도록 정리하며, 공개 자료에는 요약 내용만 포함됩니다.

**1. (필수) 어떤 입장에서 응답하시나요?**
*객관식 · 단일 선택*

- 시각장애 당사자 → 페이지 2로
- 가족·보호자 → 페이지 3으로
- 지원인력·관련 전문가 (활동지원사, 보행지도사, 복지관 종사자 등) → 페이지 3으로
- 기타 → 페이지 3으로

## [페이지 3] 게임에 담은 불편 사례

다음은 게임에 포함된 네 가지 보행 상황입니다.
각 상황에서 실제 경험이나 알고 계신 내용과 비교했을 때, **사실과 다르거나 과장되었다고 생각하는 사례를 모두 선택해 주세요.**
직접 경험하셨거나 가까이에서 관찰하신 내용을 바탕으로 답해 주세요. 잘 모르는 상황은 '판단하기 어려움'을 선택하셔도 됩니다.

**3. (필수) 상황 1. 야외 보행 중**
*체크박스 · 복수 선택*

- 점자블록 위에 세워진 킥보드, 자전거 등의 장애물
- 지팡이에 닿지 않는 머리 높이의 돌출물 (간판, 배관 등)
- 공사 등으로 점자블록이 끊기거나 가려져 이동 경로를 찾기 어려움
- 공사 소음 등으로 주변 소리를 듣기 어려움
- 모든 사례가 대체로 적절함
- 해당 상황을 잘 몰라 판단하기 어려움

**4. (필수) 상황 2. 횡단보도를 건널 때**
*체크박스 · 복수 선택*

- 음향신호기 버튼의 위치를 찾기 어려움
- 차량 소음 등으로 음향신호기의 안내음을 듣기 어려움
- 횡단보도의 경계를 알 수 없어 건너는 동안 방향을 유지하기 어려움
- 모든 사례가 대체로 적절함
- 해당 상황을 잘 몰라 판단하기 어려움

**5. (필수) 상황 3. 건물 안에서 이동할 때**
*체크박스 · 복수 선택*

- 엘리베이터의 도착 여부나 운행 방향을 확인하기 어려움
- 엘리베이터 버튼의 위치와 점자 표기를 찾기 어려움
- 방 호수를 확인하기 어려움
- 모든 사례가 대체로 적절함
- 해당 상황을 잘 몰라 판단하기 어려움

**6. (필수) 상황 4. 길안내 앱을 사용할 때**
*체크박스 · 복수 선택*

- 건물이 밀집한 곳에서 현재 위치가 정확하지 않음
- '2시 방향' 같은 방향 안내가 대략적이라 목적지를 찾기 어려움
- 실내에서 길안내 기능을 이용하기 어렵거나 안내가 부정확함
- 모든 사례가 대체로 적절함
- 해당 상황을 잘 몰라 판단하기 어려움

**7. 앞에서 실제와 다르거나 과장되었다고 선택한 사례가 있다면, 어떤 점이 다른지 알려 주세요.**
*장문형 · 선택 응답*

어떻게 표현하면 더 실제에 가까울지도 함께 말씀해 주시면 좋겠습니다.

**8. 게임에 담긴 상황이나 표현 중 불편하게 느껴지거나, 시각장애인에 대한 오해를 불러일으킬 수 있다고 생각하는 부분이 있다면 알려 주세요.**
*장문형 · 선택 응답*

## [페이지 5] 도움 경험

**11. 보행 중 다른 사람의 도움을 받거나 제공한 경험이 있다면, 어떤 방식이 좋았는지 알려 주세요.**
*장문형 · 선택 응답*

**12. 반대로 보행 중 도움을 받거나 제공하는 과정에서 불편했거나 어려웠던 경험이 있다면 알려 주세요.**
*장문형 · 선택 응답*

**13. (필수) 게임에서는 시각장애인을 도울 때 아래 방법을 안내합니다. 실제와 맞지 않거나 보완할 점이 있다고 생각하는 항목을 모두 선택해 주세요.**
*체크박스 · 복수 선택*

- 먼저 "도와드릴까요?" 하고 묻고, 원할 때만 돕기
- 갑자기 팔이나 지팡이를 잡지 않고, 상대방이 원하는 안내 방식을 확인한 뒤 팔을 잡고 따라올 수 있도록 안내하기
- "저기"보다 "오른쪽으로 다섯 걸음"처럼 구체적으로 길 알려 주기
- 안내견을 만지거나 부르거나 먹을 것을 주지 않기
- 자리를 떠날 때 말로 알려 주기
- 모든 방법이 대체로 적절함
- 잘 몰라 판단하기 어려움

**14. 13번에서 실제와 맞지 않거나 보완이 필요하다고 선택한 항목이 있다면, 어떻게 고치면 좋을지 알려 주세요.**
*장문형 · 선택 응답*

## [페이지 6] 커피 쿠폰 추첨 응모

추첨을 원하시면 아래 개인정보 수집에 동의한 뒤 휴대전화 번호를 남겨 주세요. 원하지 않으시면 '동의하지 않음'을 선택하고 제출해 주세요.

**15. (필수) 개인정보 수집 및 이용 동의**
*객관식 · 단일 선택*

- 수집 항목: 휴대전화 번호
- 이용 목적: 커피 쿠폰 추첨 및 발송
- 보유 기간: 쿠폰 발송 후 즉시 삭제
- 동의를 거부할 수 있으며, 거부하면 추첨에 참여할 수 없습니다.

선택지:

- 동의함 → 페이지 7로
- 동의하지 않음 → 제출
