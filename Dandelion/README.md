# 모드 1: 시각장애인 보행 체험

[민들레(Dandelion)](../README.md) 프로젝트의 첫 번째 체험 모드입니다.

Godot 4.3 이상을 대상으로 작성한 1인칭 3D 보행 체험 프로토타입입니다.
외부 에셋, 플러그인, 인터넷 연결이 필요하지 않습니다. Godot 3에서는 열리지 않습니다.

## 실행

1. 저장소를 clone하거나 ZIP으로 받아 압축을 풉니다.
2. Godot 4 프로젝트 관리자에서 **가져오기 / Import** → `Dandelion/project.godot`.
3. **F5**로 실행 → `전화기를 넣고, 출발한다`.

화면이 거의 검은 것은 의도된 동작입니다. 걸으면 화면 아래에 흰 지팡이가 보이고, 지팡이 끝이 닿은 곳만 잠시 드러납니다.
한글이 네모로 나오면 Noto Sans KR 등 한글 글꼴을 설치하세요. 헤드폰을 권장합니다.

## 조작

| 입력 | 기능 |
|---|---|
| W / S | 앞 / 뒤로 걷기 (지팡이가 걸음에 맞춰 자동으로 호를 그림) |
| A / D | 옆걸음 |
| 마우스 | 몸 돌리기 |
| Shift | 서두르기 (1.35배) |
| Space / 좌클릭 | 지팡이 끝으로 세게 두드리기 (울림이 조금 더 멀리 감) |
| Q | 휴대폰 음성 보행 안내 (오차 있음) |
| Esc | 도움말·일시정지 / R: 재시작 |

## v2 변경 사항

### 1. 반향 정위 범위를 실제 수준으로 축소
기존: 바라보는 곳 7m까지 원거리 타격, 타격점 반경 **15m**의 모든 윤곽이 드러남.
변경: 두 가지 감각으로 나누고 각각 짧게 제한했습니다.

| 감각 | 범위 | 대상 |
|---|---|---|
| 촉각 (지팡이 끝) | 닿은 지점 반경 0.38m, 물체에 걸리면 0.65m | 모든 것 (바닥 줄눈, 점자블록, 사물) |
| 청각 반향 (걸으며 두드림) | 최대 1.6m, 희미함(밝기 42%) | 넓고 단단한 면만 (벽, 가림막). 상자·벤치는 약하게, 기둥·바닥은 없음 |
| 청각 반향 (멈춰서 세게) | 최대 2.8m | 위와 같음 |
| 소음 구역 안 | 반향 0 | 촉각만 남음 |

- 반사율은 선마다 정점 색(`COLOR.r`)으로 지정합니다. `_box(..., reflect)` 인자로 조정하세요.
- 촉각 잔상 1.6초, 반향 잔상 0.7초. 동시 펄스 6개.
- 벽·가림막의 넓은 면에는 50cm 간격 세로선을 추가해, 반향이 닿은 '면'의 범위가 보이게 했습니다.

### 2. 이점 촉타법(two-point touch) 지팡이 모션
보행 훈련에서 가르치는 기본 기법을 그대로 따릅니다.
- 길이 1.2m 지팡이를 **몸 중앙, 배꼽 높이**에서 잡습니다 (`HAND_LOCAL`).
- 지팡이 끝은 **발 앞 약 1m**에서 **어깨보다 조금 넓게 (좌우 ±0.33m)** 호를 그립니다 (`SWEEP_ANGLE`).
- **한 걸음에 한 번**, 호의 좌우 끝에서 바닥을 두드립니다. 호 중간에는 지팡이 끝이 3.5cm 뜹니다.
- **in-step**: 왼발이 나갈 때 지팡이 끝은 오른쪽, 오른발이 나갈 때 왼쪽. 발소리도 해당 발 위치에서 납니다.
- 걸음 위상은 실제 이동 거리로 진행하므로, 벽에 막혀 제자리걸음을 하면 지팡이도 멈춥니다. 서면 다음 끝까지 마저 내려놓습니다.
- 지팡이는 매 프레임 손→끝 물리 레이로 판정합니다. 물체에 걸리면 그 자리에서 멈추고, 둔탁한 소리, 진동, 짧은 촉각 설명이 나옵니다. 걸린 채 더듬으면 0.45초마다 그 물체의 모양이 조금씩 드러납니다.
- 보행 속도를 3.4 → **1.15m/s**(지팡이 보행 평균 수준)로 낮췄습니다.
- 화면 좌측 상단의 작은 도식이 현재 호 위치와 디딘 발을 보여 줍니다.
- 바라보는 곳을 원거리 타격하던 조준점·좌클릭 7m 규칙과, 정확한 목적지 방향·거리 HUD는 삭제했습니다.

### 3. 추가한 시각장애인의 불편함
1. **머리 높이 돌출물**: 벽에서 튀어나온 간판(z=-22), 공사용 파이프(z=-41). 지팡이는 허리 아래만 탐색하므로 경고 없이 부딪힙니다. 화면 번쩍임, 흔들림, 0.9초 정지, 부딪힌 횟수 기록.
2. **막히고 끊긴 점자블록**: 출발점부터 병원 현관까지 선형 점자블록(4줄 돌기)과 꺾이는 곳의 점형블록이 있습니다. 지팡이 끝이 호를 그리며 지나갈 때 돌기를 스치는 "드르륵" 소리로 알 수 있습니다. 하지만
   - 점자블록 한가운데 **전동 킥보드**가 세워져 있고 (z=-10.5),
   - 공사로 **3.5m 구간이 뜯겨 나가** 갑자기 끊깁니다 (z=-27 ~ -30.5).
   - 지팡이가 세 걸음 동안 블록을 스치지 못하면 "놓쳤다"는 안내가 나옵니다.
3. **소음으로 인한 청각 단서 차단**: 공사 발전기(6.4, -29.5)가 반복 소음을 냅니다. 가까워질수록 반향 범위가 0으로 줄고(3m 이내 완전 차단, 9.5m부터 정상), 병원의 음향 신호기 소리도 묻힙니다.
4. (보조) **부정확한 휴대폰 안내**: Q를 누르면 "약 N미터, N시 방향"으로만 안내합니다. 15초마다 바뀌는 3~9m 위치 오차가 있습니다. OS에 한국어 TTS 음성이 있으면 소리로도 읽어 줍니다.

엔딩에는 걸린 시간과 함께 지팡이에 걸린 횟수, 머리를 부딪힌 횟수가 표시됩니다.

## 수정 포인트

| 위치 | 설정 |
|---|---|
| main.gd / SPEED, STEP_LENGTH | 보행 속도, 보폭 (한 걸음 = 호 한 번) |
| main.gd / CANE_LENGTH, HAND_LOCAL, SWEEP_ANGLE, TIP_LIFT | 지팡이 길이, 잡는 위치, 호 폭, 끝 들림 |
| main.gd / TOUCH_RADIUS, OBSTACLE_TOUCH | 촉각 범위 |
| main.gd / ECHO_WALK, ECHO_HARD | 반향 거리 |
| main.gd / NOISE_POS, `echo_gain` 계산식 | 소음원 위치와 차단 범위 |
| main.gd / _build_world `path` | 점자블록 경로 (끊김 구간은 `_paving_segment`의 index 4) |
| main.gd / _describe_contact | 물체에 걸렸을 때의 설명 문구 |
| echo.gdshader / touch_persistence, echo_persistence | 잔상 지속시간 |

새 물체는 `_box(중심, 크기, 라벨, 반사율, 윤곽, 충돌, 머리높이)`로 추가합니다. 라벨은 `_describe_contact`의 설명과 연결되고, 마지막 인자를 `true`로 주면 머리 부딪힘 판정 대상이 됩니다.

## 확인 상태

- Godot 4.3 stable (Linux)에서 import, 스크립트 파싱, 실행 오류 없음 확인.
- Xvfb + OpenGL(Compatibility) 실제 렌더링으로 자동 주행 테스트: 출발 → 킥보드 접촉 → 간판 충돌 → 점자블록 끊김 → 발전기 소음 → 파이프 충돌 → 도착 엔딩까지 약 84초에 완주, 모든 이벤트 발생 확인.
- 오디오는 Dummy 드라이버로 실행했기 때문에 실제 소리 크기와 방향감은 직접 들어 보고 조정이 필요합니다.
- Linux에서 speech-dispatcher가 없으면 시작 시 TTS 관련 오류 한 줄이 콘솔에 출력됩니다. 동작에는 영향이 없습니다.

## 한계

- 실제 보행 훈련이나 장애 체험의 정확한 재현이 아닙니다. 수치는 체험용으로 단순화한 값입니다.
- 흰 윤곽선은 촉각과 청각 정보를 화면으로 옮긴 허구적 시각화입니다.
- 메뉴 스크린리더 연동, 키 재설정은 미구현입니다. 화면에 시각장애인 캐릭터가 나오는 것과 시각장애인이 플레이할 수 있는 게임인 것은 구별되어야 합니다.
