# 프로젝트 민들레 - 자료 조사

체험 스테이지의 설계와 개발에 필요한
근거 자료 및 검토 내용을 정리하는 공간입니다.

공신력 있는 기관의 자료를 바탕으로 상황별 특성과 제약을 분석하고, 이를 게임 규칙으로 옮기는 근거로 사용합니다.

## 폴더 안내

| 폴더 | 내용 | 상태 |
|---|---|---|
| [`시각장애_보행/`](시각장애_보행/) | 시각장애 보행 체험의 설계 근거 자료 (기관 보고서, 참고자료 정리) | 정리됨 |
| [`재난상황_화재/`](재난상황_화재/) | 화재 상황의 제약과 행동 요령 체험 자료 | 준비 중 |
| [`설문조사/`](설문조사/) | 플레이어와 당사자의 의견을 모으기 위한 설문 양식과 결과 요약 | 준비 중 |

## 자료 정리 규칙

- 새 체험의 자료는 체험 이름으로 폴더를 만들고, 안에 `README.md`를 둡니다. (자료 목록과 활용 범위)
- 자료마다 발행기관, 연도, 링크를 함께 적습니다.
- 수치와 규격을 게임에 반영할 때는 요약이 아니라 원문의 해당 항목을 확인합니다.
- 개인정보가 담긴 원본 응답, 인터뷰 녹음과 녹취록은 올리지 않습니다.
