# 민들레 (Dandelion)

> 경험해 보지 못한 상황을, 게임으로 체험하다

**민들레**는 직접 경험할 기회는 적지만 그 특성과 어려움, 판단의 중요성을 이해할 필요가 있는 상황을 게임으로 체험하는 오픈 소스 교육 게임입니다. 일상생활의 제약, 특정 직업의 업무 환경, 재난 같은 비상 상황을 조사해 게임 규칙으로 바꾸고, 플레이어가 직접 판단하고 행동하며 그 상황을 이해하도록 만듭니다. Godot 엔진으로 만들며, 체험을 하나씩 늘려 갑니다.

길가에 핀 민들레처럼, 사람들이 평소에 무관심하게 지나친 것들의 중요성을 배우자는 뜻을 담았습니다.

*Dandelion is an open-source Godot game of short experiences that let players feel situations they rarely face themselves — starting with walking a city street with a white cane. The UI and documentation are currently in Korean.*

### 시각장애 보행

화면은 거의 검은색입니다. 지팡이로 짚은 곳과, 두드린 소리가 넓은 벽에 부딪혀 돌아오는 희미한 울림만 잠시 윤곽으로 드러납니다.

- **연습 구간**: 집 앞 아파트 복도에서 점자블록 따라가기, 웅크리기, 휴대폰 안내, 버튼 누르기를 먼저 익힙니다. (건너뛸 수 있음)
- **흰 지팡이**: 걸으면 걸음에 맞춰 지팡이가 좌우를 번갈아 짚고(이점 촉타법), 마우스로 겨눈 곳을 지팡이 길이(1.2m) 안에서 직접 짚어 확인할 수도 있습니다.
- **웅크리기**: 지팡이로 알 수 없는 머리 높이의 간판과 파이프는 몸을 낮춰 피합니다.
- **길 위의 불편**: 점자블록 위 전동 킥보드, 머리 높이의 간판과 공사 파이프, 공사로 뜯겨 나간 점자블록, 안내음을 덮는 발전기 소음, 오차가 큰 휴대폰 위치 안내
- **신호등 횡단보도**: 음향신호기의 위치 알림음을 찾아 버튼을 누르고, 녹색 신호 안내와 건너편 유도음을 따라 건넙니다. 횡단보도의 흰 칠은 지팡이로 느낄 수 없습니다.
- **도와주는 사람**: 점자블록을 1분 넘게 찾지 못하면 지나가던 사람이 “도와드릴까요? 제가 팔을 살짝 터치해도 될까요?”라고 먼저 묻고, 마지막으로 점자블록이 있던 곳까지 함께 걸어 줍니다.
- **병원 엘리베이터와 병실**: 엘리베이터가 오는 것을 소리로만 기다리고, 버튼의 점자를 손끝으로 더듬어 5층을 누르고, 문 옆 점자 명패로 503호를 찾습니다.

엔딩에서는 걸린 시간, 지팡이에 걸린 횟수, 머리를 부딪힌 횟수, 경적과 도움을 받은 횟수를 보여 주고, 마지막 페이지 **‘함께 걷는 법’**에서 길에서 시각장애인을 배려하고 돕는 방법을 정리합니다. 자세한 규칙과 조정 가능한 값은 [`Dandelion/README.md`](Dandelion/README.md)에 있습니다.

## 실행하기

### 바로 실행 (Windows)

GitHub의 **Releases**에서 해당 버전의 `Dandelion.exe`를 내려받아 더블클릭하면 됩니다. Godot를 설치할 필요가 없습니다.
처음 실행할 때 Windows SmartScreen이 “Windows의 PC 보호” 창을 띄우면 **추가 정보 → 실행**을 누르세요. (서명하지 않은 실행 파일이라 나오는 경고입니다)

### Godot에서 열기 (개발용)

**필요한 것:** [Godot 4.3 이상](https://godotengine.org/download) (표준 버전, .NET 불필요). 외부 에셋, 플러그인, 인터넷 연결은 필요하지 않습니다. Godot 3에서는 열리지 않습니다.

1. 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/norussi/-_project_dandelion.git
   ```
   또는 GitHub의 **Code → Download ZIP**으로 받아 압축을 풉니다.
2. Godot 프로젝트 관리자에서 **가져오기(Import)** → `Dandelion/project.godot`을 선택합니다.
3. **F5**로 실행합니다. 메인 메뉴에서 **플레이** → **시각장애 보행**의 **시작하기**를 누릅니다.

헤드폰을 권장합니다. 한글이 네모로 보이면 Noto Sans KR 같은 한글 글꼴을 설치하세요.

### 메인 메뉴와 설정

- **플레이**: 체험을 고르는 화면이 열립니다.
- **설정**: 조작(마우스 감도, 상하 반전, 시야각, 조준점), **키 설정**, 소리(전체 음량, 음성 안내 켜기·음량·속도), 화면·접근성(전체 화면, 글자 크기, 화면 흔들림·번쩍임 끄기). 바꾼 값은 바로 적용되고 자동으로 저장됩니다. 게임 중에도 일시정지 화면에서 열 수 있습니다.
- **GitHub 바로가기**: 오른쪽 아래에서 이 저장소를 엽니다.

### 기본 조작 (설정에서 바꿀 수 있음)

| 입력 | 기능 |
|---|---|
| W / S, A / D | 걷기, 옆걸음 |
| 마우스 | 몸 돌리기, 고개 숙이기 |
| (걷기) | 지팡이가 걸음에 맞춰 좌우를 자동으로 짚음 (설정에서 끌 수 있음) |
| 좌클릭 | 바라보는 곳을 지팡이로 짚기 (손에서 1.2m 이내) |
| Space | 발 앞 짚기 |
| E | 손으로 더듬기 (신호기 버튼, 엘리베이터 버튼, 문 옆 명패) |
| Q | 휴대폰 음성 안내 (오차 있음, 실내 불가) |
| Shift | 서두르기 |
| Ctrl | 웅크리기 (누르고 있는 동안) |
| Esc / R | 일시정지·도움말 / 처음부터 다시 |

### 실행 파일 만들기 (내보내기)

`Dandelion/export_presets.cfg`에 Windows와 Linux 내보내기 설정이 들어 있습니다.

1. Godot 에디터와 **같은 버전의 내보내기 템플릿**을 설치합니다. (에디터 메뉴 **편집기 → 내보내기 템플릿 관리 → 다운로드 및 설치**)
2. **프로젝트 → 내보내기** → `Windows Desktop` → **프로젝트 내보내기**. 결과는 저장소 루트의 `build/windows/Dandelion.exe`에 생깁니다.
3. `build/` 폴더는 `.gitignore`에 들어 있어 커밋되지 않습니다. 실행 파일은 약 105MB로 GitHub의 파일 크기 제한(100MB)을 넘으므로, 저장소에 넣지 말고 **Releases**에 첨부해 배포합니다.

명령줄로 내보낼 수도 있습니다: `godot --headless --path Dandelion --export-release "Windows Desktop" ../build/windows/Dandelion.exe`

## 저장소 구조

```
.
├── Dandelion/                    # Godot 4 프로젝트
│   ├── project.godot             # 시작 씬: 메인 메뉴
│   ├── icon.png, icon.ico        # 민들레 아이콘
│   ├── core/                     # 설정·키 설정(Settings), 체험 목록과 화면 전환(Game), 메뉴 테마
│   ├── menu/                     # 메인 메뉴, 길가 민들레 배경, 체험 선택, 설정 화면
│   ├── stages/
│   │   ├── visual_walk/          # 체험 1: 시각장애 보행 (씬, 스크립트, 셰이더)
│   │   └── fire_escape/          # 체험 2: 화재 대피를 민들레에 연결하는 씬 (일시정지, 메뉴 복귀)
│   ├── main.tscn, map.tscn       # 체험 2 본체: 게임 씬과 학교 맵
│   ├── scripts/, parts/, materials/, shaders/  # 체험 2 본체: 스크립트, 부품, 재질, 셰이더
│   └── README.md                 # 게임 상세 설명, 새 체험 추가하는 법
├── docs/research/                # 체험 설계를 위한 자료 조사 (기관 보고서, 참고자료 정리)
├── CHANGELOG.md
├── CONTRIBUTING.md
├── CODE_OF_CONDUCT.md
└── LICENSE
```

새 체험은 `Dandelion/stages/` 아래에 폴더를 만들고 `Dandelion/core/game.gd`의 체험 목록(`STAGES`)에 한 줄을 추가하면 체험 선택 화면에 나타납니다. 자세한 방법은 [`Dandelion/README.md`](Dandelion/README.md#새-체험-추가하는-법)를 보세요.

## 이 체험이 아닌 것

- 실제 장애나 보행 훈련을 정확히 재현하지 않습니다. 수치는 체험을 위해 단순화한 값입니다.
- 흰 윤곽선은 촉각과 청각 정보를 화면으로 옮긴 허구적 시각화입니다. 시각장애인이 세상을 이렇게 '본다'는 뜻이 아닙니다.
- 게임 속 점자는 팀이 직접 점역한 것으로, 아직 점역·교정 전문가의 확인을 받지 않았습니다.
- 화면에 시각장애인 캐릭터가 나오는 것과 시각장애인이 플레이할 수 있는 게임인 것은 다릅니다. 키 재설정은 v0.2.0에서 추가했지만, 스크린리더 연동은 아직 구현하지 않았습니다.

당사자의 경험과 다르거나 오해를 부를 수 있는 부분을 발견하면 꼭 알려 주세요.
