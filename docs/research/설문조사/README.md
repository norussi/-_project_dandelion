# 설문조사

게임을 체험한 플레이어와 당사자의 의견을 모아 개선 버전에 반영하기 위한 설문 자료를 정리하는 공간입니다.

## 목적

공개한 테스트 버전을 바탕으로 설문과 인터뷰로 당사자와 플레이어의 의견을 수집하고, 이를 반영해 개선 버전을 만듭니다.

## 폴더에 올리는 것

- 설문 양식(질문 문항)
- 설문 목적, 대상, 진행 기간을 적은 설명
- 개인을 알아볼 수 없게 정리한 결과 요약과 개선에 반영한 내용

## 올리지 않는 것

- 이름, 연락처 등 개인정보가 담긴 원본 응답
- 인터뷰 녹음과 녹취록 원본
- 응답자의 동의 범위를 벗어나는 내용
